# Python PBL – Credit Card Fraud Detection System

## Overview
This project is an AI/ML-based Credit Card Fraud Detection System developed as part of the Python PBL project.
The main objective of this project is to identify fraudulent financial transactions using Machine Learning techniques, data preprocessing, visualization, and analytical methods.
The project combines:
- Data Analysis
- Feature Engineering
- Data Balancing
- Machine Learning Models
- Fraud Prediction Techniques
to improve fraud detection accuracy.
## Project Features
### Exploratory Data Analysis (EDA)
Performed detailed EDA using:
- Distribution plots
- Correlation analysis
- Heatmaps
- Transaction behavior analysis
### Data Preprocessing
- Handling missing values
- Feature scaling
- Data cleaning
- Removing irrelevant/useless features
- Feature engineering
### Data Balancing
Implemented SMOTE (Synthetic Minority Oversampling Technique) to balance fraudulent and non-fraudulent transaction data.
### Machine Learning Model
Trained fraud detection models using Machine Learning techniques for transaction classification.
### Model Evaluation
Evaluated model performance using:
- Confusion Matrix
- ROC Curve
- Accuracy Score
- Precision
- Recall
- F1 Score
- Threshold Analysis
### Fraud Prediction
The system predicts whether a transaction is:
- Fraudulent
- Non-Fraudulent
